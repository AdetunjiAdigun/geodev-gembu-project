# My project brief

## The question

Which built-up areas in Gembu, Taraba State are located close to major watercourses?

## The data I need

- Built-up/settlement areas — OpenStreetMap — QuickOSM plugin inside QGIS
- Watercourses — OpenStreetMap — QuickOSM plugin inside QGIS
- Administrative boundaries — GeoFabrik — download.geofabrik.de/africa/Nigeria.html
- Satellite imagery — USGS EarthExplorer — https://earthexplorer.usgs.gov
- Elevation data — Copernicus DEM — https://dataspace.copernicus.eu
